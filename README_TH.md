# Workout Tracker Android
โปรเจกต์ Android Studio (Kotlin + Jetpack Compose) สำหรับโปรแกรม 5 วัน รวม 62 เซต

วิธีสร้าง APK:
1. ติดตั้ง Android Studio บนคอมพิวเตอร์
2. แตก ZIP แล้วเปิดโฟลเดอร์ WorkoutTrackerAndroid ด้วย Android Studio
3. รอ Gradle Sync (ต้องใช้อินเทอร์เน็ตครั้งแรก)
4. เลือก Build > Build Bundle(s) / APK(s) > Build APK(s)
5. กด Locate เพื่อหาไฟล์ APK แล้วส่งไปติดตั้งบนมือถือ Android

แอปมีปุ่มเพิ่ม/ลดเซต สรุปความคืบหน้า ธีมมืด และบันทึกจำนวนเซตไว้ในเครื่องเมื่อปิดแอป

หมายเหตุ: ZIP นี้เป็นซอร์สโปรเจกต์ Android Studio ไม่ใช่ APK ที่คอมไพล์แล้ว
